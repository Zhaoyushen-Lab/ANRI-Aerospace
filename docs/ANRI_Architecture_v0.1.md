# ANRI Architecture v0.1

## Overview

ANRI (AI-Native Research Infrastructure)
is an experimental framework for exploring
AI-assisted aerospace conceptual design.

The goal is to build a workflow where AI agents
can participate in multidisciplinary engineering tasks.

The first application scenario is
Cross-Domain Flight Vehicle Design (ANRI-CDFV).
