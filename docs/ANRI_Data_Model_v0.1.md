# ANRI_Data_Model_v0.1


## 1. Knowledge Object

Purpose:

Represent reusable engineering knowledge accumulated by ANRI.

Contains:

- domain
- concept
- source
- confidence
- related topics


---

## 2. Problem Object

Purpose:

Represent engineering problems derived from mission requirements.

Contains:

- objective
- constraints
- environment
- required disciplines


---

## 3. Decision Object

Purpose:

Record engineering decisions and their reasoning process.

Contains:

- problem
- assumptions
- alternatives
- selected solution
- reasoning
- result


---

## 4. Experiment Object

Purpose:

Record experiments, simulations, and validation processes.

Contains:

- objective
- method
- input
- output
- conclusion
