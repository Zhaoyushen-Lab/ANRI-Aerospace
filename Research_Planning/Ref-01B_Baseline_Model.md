# Ref-01B Baseline Model

## Metadata

- Model ID: CDFV-001-Ref-01B-Baseline
- Configuration: CDFV-001-Ref-01B
- Parent task: P003
- Parent evidence: P002 / E002-001
- Model type: Prescribed-motion vertical transition model
- Status: Interface defined; parameter completion pending
- Experimental validation: Deferred
- CDFV transfer: Not established

## 1. Purpose

Define the simplest computable model for vertical water-exit
transition using the P002 benchmark configuration.

The purpose is to compare:

1. a baseline loading model without a free-surface term; and
2. an extended model containing a candidate free-surface term.

This model is a computational benchmark.
It is not a validated CDFV-001 vehicle model.

## 2. Modeling Mode

The first version uses prescribed-motion analysis.

This means that the vertical motion is treated as an input,
rather than being generated by a detailed propulsion model.

The initial model does not include:

- rotor thrust dynamics;
- autonomous control;
- horizontal motion;
- changing attitude;
- arm or appendage effects;
- full six-degree-of-freedom dynamics.

## 3. Coordinate Convention

- Vertical coordinate: z
- Positive z direction: upward
- Vertical velocity: v = dz/dt
- Vertical acceleration: a = d²z/dt²
- Gravity direction: downward
- Force output: positive upward
- Attitude: fixed upright reference attitude

The force sign convention must be kept separate from the sign
convention used in the P002 figures.

## 4. State Variables

- z(t): vertical position
- v(t): vertical velocity
- a(t): vertical acceleration

State vector:

x(t) = [z(t), v(t)]

with:

v(t) = dz/dt

and:

a(t) = dv/dt

## 5. Model Inputs

Required inputs:

- model mass m;
- body geometry;
- displaced volume as a function of immersion;
- water density;
- gravitational acceleration;
- prescribed velocity v(t);
- prescribed acceleration a(t);
- initial immersion condition;
- fixed attitude;
- optional free-surface loading term.

## 6. Model Outputs

Primary outputs:

- vertical position;
- vertical velocity;
- vertical acceleration;
- baseline force contribution;
- candidate free-surface force contribution;
- extended-model force estimate;
- difference between baseline and extended models.

## 7. Force Decomposition

The total vertical force is represented as:

F_total =
    F_actuation
  + F_buoyancy
  + F_weight
  + F_resistance
  + F_added_mass
  + F_free_surface

The first model does not require every term to be numerically
available. Each term must be marked as included, excluded,
assumed, or blocked.

## 8. Baseline Model

The baseline model excludes the free-surface contribution:

F_free_surface = 0

The baseline force interface is:

F_baseline =
    F_actuation
  + F_buoyancy
  + F_weight
  + F_resistance
  + F_added_mass

For the first computational pass, the following terms are used:

- gravity: included;
- buoyancy: included as a geometry-dependent term;
- actuation: prescribed motion input or constraint reaction;
- resistance: not yet parameterized;
- added mass: not yet parameterized;
- free-surface loading: excluded.

## 9. Extended Model

The extended model adds a candidate free-surface contribution:

F_extended =
    F_baseline
  + F_free_surface(z, v)

The function F_free_surface is not yet selected.

It must not be copied directly from P002 until the following
questions are answered:

- Is the force normalized or dimensional?
- What is its exact direction?
- What is the reference frame?
- What geometry does the fit apply to?
- What velocity range is valid?
- Does it represent an isolated suction force or a resultant force contribution?

## 10. Hydrostatic Terms

Weight:

W = m × g

Buoyancy:

B(z) = rho_water × g × V_displaced(z)

where:

- rho_water is the assumed water density;
- V_displaced(z) is the submerged volume;
- g is gravitational acceleration.

For Ref-01B, the initial geometry is the P002 cylindrical
benchmark:

- diameter: 0.090 m;
- length: 0.323 m;
- mass: 2.030 kg.

The fully submerged volume estimate is:

V_full = pi × (D / 2)^2 × L

This estimate is derived from geometry and is not a directly
reported P002 measurement.

## 11. Prescribed-Motion Interpretation

Because the first model prescribes the trajectory, the model
does not yet solve for propulsion thrust.

The prescribed inputs are:

- z(t);
- v(t);
- a(t).

The analysis should report:

- hydrostatic loading;
- known or assumed hydrodynamic contributions;
- missing terms;
- the residual required to explain the prescribed motion.

The residual must not automatically be labeled as free-surface
suction. It may include resistance, added mass, constraint force,
or other unmodeled effects.

## 12. Benchmark Cases

### Case B-01

- Velocity: 0.10 m/s
- Purpose: lower end of the P002 water-exit range
- Free-surface term: excluded in baseline
- Status: Defined

### Case B-02

- Velocity: 0.25 m/s
- Purpose: reported transition toward the suction plateau
- Free-surface term: excluded in baseline
- Status: Defined

### Case B-03

- Velocity: 0.50 m/s
- Purpose: upper end of the P002 water-exit range
- Free-surface term: excluded in baseline
- Status: Defined

Acceleration profiles and initial immersion depths remain open
because they are not fully specified for all P002 velocity cases.

## 14. Assumptions

- The body is rigid.
- Motion is vertical.
- Attitude is fixed.
- The free surface is initially calm.
- P002 geometry is used only as a benchmark.
- Freshwater properties are provisional.
- The model does not claim to represent a complete CDFV vehicle.
- Missing hydrodynamic coefficients are not invented.

## 15. Limitations

- The model does not reproduce the full P002 experiment.
- No raw force-time dataset has been recovered.
- Initial immersion and acceleration histories remain incomplete.
- Resistance and added-mass terms are not yet identified.
- The P002 force sign convention requires separate checking.
- CDFV-specific transfer has not been demonstrated.
- Experimental validation is deferred because laboratory resources
  are not currently available.

## 16. Completion Criteria

The first Ref-01B baseline version is complete when:

- the coordinate convention is explicit;
- the modeling mode is explicit;
- baseline and extended models are distinguished;
- all known parameters have sources;
- all unknown parameters are marked as open or blocked;
- the three benchmark cases are defined;
- no residual force is incorrectly labeled as free-surface suction;
- no CDFV-specific validation claim is made.

## 17. Next Task

The next task is baseline sensitivity analysis.

The sensitivity analysis should vary:

- mass;
- water density;
- displaced volume;
- water-exit velocity;
- initial immersion;
- resistance coefficient, once defined.

The analysis should determine which missing parameters
materially affect the baseline result.
