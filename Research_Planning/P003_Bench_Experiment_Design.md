## 1. 这个实验要回答什么

`P003` §7.5.11 已把 6 个假说收敛为 3 类：

| 类 | 机制 | 是否需要体积亏缺 |
|---|---|---|
| **A** | H5 附加质量梯度 | **否** |
| **B** | H2 ≡ H6 水位变化 / 水膜 | 是（水仍在） |
| **C** | H4 空腔 | 是（空气占据） |

**三台测量，各给一位信息：**

| 位 | 测量 | 分离 |
|---|---|---|
| **1** | 力–时间历程（恒速上提） | A ↔ B/C |
| **2** | 出水后称重 | B ↔ C |
| **3** | 自由液面形状 | H2 ↔ H6（若为 B） |

**本设计只覆盖位 1 与位 2。位 3 用手机摄像头另做，不在此文件冻结。**

## 2. 几何与工况

### 2.1 试件（与 P002 同尺度，才能对照）

| 项 | 值 |
|---|---|
| 形状 | **平头圆柱**（flat-faced，两端平面） |
| 直径 `D` | **0.090 m** |
| 长度 `L` | **0.323 m** |
| 质量 `m` | 目标 **2.030 kg**（可微调以匹配） |
| 材料 | 需可机加工/3D 打印并密封；密度须能配到 ~988 kg/m³ |

**⚠️ 实现难点**：`ρ_body = 2.030 / 2.0548e-3 = 988 kg/m³`，略低于水。
**普通塑料（~950–1050）可调；需在顶部/底部加配重腔。**

### 2.2 速度（对齐 P002 的 Fr 区间）

| `v` (m/s) | `Fr_D = v/√(gD)` | 对应 P002 |
|---|---|---|
| 0.05 | 0.053 | 低于区间 |
| **0.10** | **0.106** | P002 下界 |
| **0.25** | **0.266** | P002 饱和点 |
| **0.50** | **0.532** | P002 上界 |

**最少测 0.10 / 0.25 / 0.50 三档。** 若采样率允许，加 0.05 作为准静态参考。

## 3. 器材要求（不含型号与价格）

### 3.1 力测量

| 项 | 要求 |
|---|---|
| 量程 | **≥ 50 N**（干重 19.9 N + 附加上限） |
| 分辨率 | **≤ 0.02 N**（吸力约 2 N，需看清 1%） |
| 采样率 | **≥ 200 Hz 优先**；最低 100 Hz |
| 安装 | 传感器串在提拉链上，**只承受竖直力** |

**⚠️ 采样率与速度的冲突（必须正视）**：

```
v = 0.50 m/s，行程 L = 0.323 m → 通过时间 0.65 s
  @100 Hz → 65 点
  @200 Hz → 130 点
```

**若采样率只能到 100 Hz，则高速档只能得 65 点——够看峰值，不够看形状。**
**取舍**：峰值用于位 1（A vs B/C），形状用于后续。**先保峰值。**

### 3.2 提拉

| 方案 | 优点 | 缺点 |
|---|---|---|
| 砝码–滑轮（重力驱动） | **便宜**，天然近似恒速 | 需低摩擦导轨；速度由质量比决定 |
| 丝杠 + 步进电机 | 速度精确可控 | 成本高 |

**推荐先做砝码–滑轮**，前提是：砝码重量 >> 阻力，且导轨摩擦小。

### 3.3 容器与水

| 项 | 要求 | 理由 |
|---|---|---|
| 内截面 `A_c` | **≥ 0.25 m²**（约 50×50 cm） | 见 §3.3.1 |
| 水深 | ≥ `L` + 0.10 m 余量 | 保证完全浸没起始 |
| 水质 | 自来水即可，**须记录温度**（密度修正） | ρ 随温度变 |

#### 3.3.1 ⚠️ 水位变化：必须算，不能忽略

**物体没入时水位上升**：

```
Δh = V_sub / A_c
```

| 容器 | `A_c` | `Δh`（满浸没） | 相对速度修正 |
|---|---|---|---|
| 30×30 cm | 0.09 m² | **22.8 mm** | **+7.1%** |
| **50×50 cm** | **0.25 m²** | **8.2 mm** | **+2.5%** |
| 100×100 cm | 1.0 m² | 2.1 mm | +0.6% |

**修正量**（物体相对水的速度）：

```
v_rel = v_lab · (1 + A_body / A_c),   A_body = π(D/2)² = 6.36e-3 m²
```

**要求**：`A_c ≥ 0.25 m²`，使修正 ≤ 3%；**并且必须记录 `A_c` 并在分析中施加修正。**
**不得以"容器够大"为理由省略修正。**

## 4. 装配要点

| # | 要求 | 原因 |
|---|---|---|
| 1 | **防摆动**：试件沿导轨或长杆竖直运动，侧向自由度为 0 | 侧向力会污染竖直分量 |
| 2 | 传感器与试件之间**刚性连接**，无软绳 | 软绳会低通滤波，削掉峰值 |
| 3 | 试件轴线与重力方向**同轴** | 偏心会产生弯矩，读进传感器 |
| 4 | 起始位置：**顶面距静水面 ≥ 5R**（≥ 0.225 m） | 与陈宇翔的 `Vt/R = −5` 起点对齐，便于对照 |
| 5 | 出水段：**顶面越过静水面 ≥ 2R** | 保证完全出水 |
| 6 | 记录**水温**与**室温** | 密度与表面张力修正 |

## 5. ★ 预先冻结的"可用数据"判据（`D-ANRI-011` §6 引用此节）

**测量前冻结。不得事后放宽。全部满足才算"可用数据"。**

| # | 判据 | 阈值 | 怎么测 |
|---|---|---|---|
| **U1** | 静重可复现 | 干重 10 次称量，极差 **≤ 0.02 N** | 空载 |
| **U2** | 空载噪声 | 试件悬空静止 5 s，力信号标准差 **≤ 0.02 N** | 空载 |
| **U3** | 恒速性 | 浸没段到出水段的速度变化 **≤ ±5%** | 位移–时间求导 |
| **U4** | 重复性 | 同速度 3 次，**峰值力极差 ≤ 峰值的 10%** | 3 次重复 |
| **U5** | 可提取性 | `F_suction(t) = F_z(t) − [W − ρg V_sub(t)]` **无需拟合**即可算出 | 后处理 |

**U5 的 `V_sub(t)` 由位移与几何算出，不依赖任何模型假设**——这是 B1 预注册规定的方法。

**若任一判据不满足**：不得称为"可用数据"；`D-ANRI-011` §6 的日期判据**不视为达成**。

## 6. 数据格式

每次运行一个 CSV，**列固定**：

```
t_s, F_z_N, z_m, v_lab_m_s, T_water_C, run_id
```

元数据单独一个 `run_meta.json`：

```json
{
  "run_id": "BENCH-YYYYMMDD-HHMM-<speed>",
  "D_m": 0.090, "L_m": 0.323,
  "m_kg": 0.0,
  "A_c_m2": 0.0,
  "rho_water_kg_m3": 0.0,
  "speed_target_m_s": 0.0,
  "operator": "",
  "apparatus": "",
  "notes": ""
}
```

**要求**：CSV 用 LF 换行、UTF-8；进入仓库后按 ANRI 的哈希登记流程处理。

## 7. 分析骨架

```
1. 读 CSV + meta
2. 由 z(t) 与几何算 V_sub(t)，并施加水位修正 v_rel
3. F_suction(t) = F_z(t) − [W − ρ g V_sub(t)]
4. 峰値 P = max_t |F_suction(t)|
5. 归一化：P/W 与 P/(½ ρ v² A_body)
6. 位 1 判据：F_suction 峰值随 v 的变化 —— 是 ∝ v² 还是饱和？
     ∝ v²  → A 类（H5）
     饱和   → B/C 类
7. 出水后称重 Δm → 位 2
     Δm ≈ 0.20 kg → B 类
     Δm ≈ 0        → C 类
```

**⚠️ 第 6 步只区分 A 与 B/C，不区分 B 与 C。第 7 步才区分 B 与 C。**

## 8. 已知局限（必须随结果报告）

| # | 局限 | 影响 |
|---|---|---|
| 1 | **单尺度** | 不能回答迁移性（B1），只能答机制 |
| 2 | 台面提拉速度可能不稳 | 若非恒速，`F = −½v²∂m/∂Z` 不适用 |
| 3 | 砝码–滑轮有摩擦 | 会偏置力读数；力矩向须标定 |
| 4 | 采样率有限 | 高速档形状不可靠，只保峰值 |
| 5 | 容器有限 | 水位修正必须做，否则混入 H2 假信号 |
| 6 | 自来水 | 表面张力随水质变；与 P002 的水可能不同 |

## 9. 与 B1 的关系

**本设计不是 B1。** B1 需要**两个尺度 + 同 Fr**，才能检验迁移性。

**本设计只做单尺度、只答机制。**

**但它是 B1 的热身**：同一套传感器、同一份数据格式、同一个 `F_suction` 提取方法。
**若台面实验跑通，B1 的实现风险会显著下降。**

## 10. 方法论声明

- **事实部分**：P002 几何与质量、`ρ_body = 988 kg/m³`、`Fr_D` 三档、
  `V = 2.0548e-3 m³`、`A_body = 6.36e-3 m²`、水位修正公式与表内数值，
  均为由已记录的 P002 参数直接计算。
- **判断部分**：§3.2 的方案推荐、§4 的装配要求、§5 的阈值取值、
  §8 的局限清单，**均为判断**。
- **未核实**：器材的具体价格与型号；`A_c ≥ 0.25 m²` 的容器是否易得；
  砝码–滑轮方案能否达到 U3（±5% 恒速）——**这一条最可能失败，须先做 U3 的预试验。**
- **本文件不含任何数据。** 它是设计，不是结果。
