## 1. 为什么 B1 是这个形状

P002 的 1.99 N 既不能由动压（≤6.4%）也不能由表面张力（1.03%）解释，
量级自洽的只有空腔体积亏缺假说。但**B1 不需要先确认该假说**。

原因：迁移所依赖的不变量是 `F_suction/W` 这个**无量纲比值**。空腔体积与排水体积
同为 L³，故其比值在严格相似下与尺度无关——**无论空腔机制的具体形式如何**，
只要它由几何与 Froude 数支配，该比值就应当尺度不变。

因此 B1 是**对迁移前提的直接检验**，而不是对机制的检验。
这也使它成为最便宜的可行路径：不需要自由液面成像，只需力与几何。

## 2. 相似性条件（必须同时满足）

| 条件 | 要求 | 理由 |
|---|---|---|
| 几何相似 | 同一 CAD、同一柱径比 D/L、同一浸没历史 | 空腔形态由几何支配 |
| **Froude 数匹配** | `Fr_D = v/√(gD)` 两尺度相等 | 自由液面与空腔的惯性—重力平衡 |
| 密度比匹配 | `ρ_w/ρ_body,eff` 两尺度相等 | `F_suction/W` 正比于密度比 |
| 浸没史匹配 | 初始浸没深度 / L 相等；速度史同形 | 空腔从何处起、如何贯通取决于此 |
| 排除表面张力 | `Fr_D` 与 `We` 不要求同时相似，但需记录 `We` 以确认非表面张力区 | 已在量级上判除，但需记录 |

**速度换算**（Froude 相似）：`v = Fr_D · √(g·λ·D)`，λ 为尺度比。

| 工况 | λ = 0.5 模型 | λ = 1.0（P002 尺寸） | λ = 2.0 |
|---|---:|---:|---:|
| Fr_D = 0.106 | 0.0704 m/s | 0.0996 m/s | 0.1408 m/s |
| **Fr_D = 0.266（P002 饱和点）** | **0.1767 m/s** | **0.2499 m/s** | **0.3534 m/s** |
| Fr_D = 0.532 | 0.3534 m/s | 0.4998 m/s | 0.7068 m/s |

> 由 `v = Fr_D·√(g·λ·D)` 计算，D = 0.090 m，g = 9.80665 m/s²，λ = 尺度比。
> **自检**：λ=1.0 行必须复现 P002 的标称工况——Fr_D = 0.266 → 0.2499 m/s
> （P002 报告 0.25 m/s，一致到 0.04%）；Fr_D = 0.532 → 0.4998 m/s（P002 报告 0.5 m/s）。
> 该自检通过，故本表可作为预注册的换算依据。
>
> **修订记录**：本表初版（同日）在 λ=0.5 与 λ=2.0 两列有误
> （误用 λ=1.0 的速度代替 √λ 换算）。已按上式重算并加入上述自检。
> 该错误由独立复算发现，未进入任何测量计划。

## 3. 测量矩阵

| 工况 | λ=0.5 | λ=1.0 | λ=2.0 | 备注 |
|---|---|---|---|---|
| Fr_D = 0.106 | ✓ | ✓（=0.10 m/s） | ✓ | 饱和前区 |
| **Fr_D = 0.266** | ✓ | ✓（=0.25 m/s） | ✓ | **饱和点，主判据** |
| Fr_D = 0.532 | ✓ | ✓（=0.50 m/s） | ✓ | 饱和后区 |

**最少可行子集**：若只能做两尺度，取 **λ = 0.5 与 λ = 1.0**，
只做 **Fr_D = 0.266** 一个工况。这已足以检验 A-P003-002。

每个工况 ≥3 次重复（P002 的自报重复性误差 ≤15%，见 `Paper_Notes` §6.2）。

**密度比匹配**：λ=0.5 与 λ=0.1 模型需配重到 `ρ_body,eff` 与 P002 圆柱相等
（**988 kg/m³** = 2.030 kg / 2.0548e-3 m³）。这是本规格中最容易被忽略的一项：
若模型轻于该密度，`F_suction/W` 会因分母变小而偏大，产生**伪尺度效应**。

## 4. 输出量与判据

### 4.1 记录项（每个工况）

| 量 | 单位 | 说明 |
|---|---|---|
| `F_z(t)` | N | 合力 Z（测量坐标系），保留原始参考约定 |
| `z(t)` | m | 柱心相对静水面的高度 |
| `v(t)` | m/s | 垂向速度 |
| `F_suction` | N | 从 `F_z(t)` 中按**同一记录方法**提取的载荷（见 4.2） |
| `W` | N | 模型重量（实测） |
| `ρ_body,eff` | kg/m³ | 实测质量 / 几何体积 |
| `Fr_D` | — | `v/√(gD)` |
| `We` | — | `ρv²D/σ`（记录用，确认非表面张力区） |

### 4.2 提取方法必须一致（关键）

P002 报告的"吸入力"是**从合力 Z 中提取并拟合的残差**（`Paper_Notes` §5、§14）。
因此 B1 必须在两个尺度上使用**完全相同的提取与拟合方法**，
否则测到的差异可能来自提取方法而非尺度。

**要求**：提取方法、时间窗、拟合形式与窗口，须在测量前以书面形式固定
（预注册），测量后不得更改。

### 4.3 通过 / 不通过判据

主判据：饱和工况（Fr_D = 0.266）下两尺度的 `F_suction/W` 之比。

| 结果 | 判定 | 对 D002-001 的后果 |
|---|---|---|
| 比值在 **1 ± 0.20** 内（即差异 ≤20%） | **A-P003-002 未被证伪**，尺度无关性成立 | 转为 **Accepted**（附无量纲适用条件） |
| 比值超出 1 ± 0.20 但方向与某一候选机制一致（如表面张力 → 小尺度偏大） | 尺度无关性不成立，但机制可辨 | 转为 **Needs CDFV experiment**（无条件），并记录所辨机制 |
| 比值超出 1 ± 0.20 且方向无解释 | 尺度无关性不成立 | 转为 **Needs CDFV experiment**（无条件） |

**±20% 阈值的来源与局限**：P002 自报重复性误差 ≤15%，
两尺度各含该量级误差，故 20% 是**误差传播下的最小可辨差异**，
不是物理显著性阈值。若重复性实测更差（例如 >15%），本阈值须相应放宽并重述。
**该阈值是判断，不是测量。**

## 5. 已知会污染结果的因素（逐条设防）

| 风险 | 控制 |
|---|---|
| 连接杆影响力矩与流动 | 记录杆长与直径；两尺度使用**几何相似**的杆（P002 杆长为 1.0 / 0.1 / 0.30 m，非相似——**不可沿用**） |
| 平台振动（P002 在 ≥0.2 m/s² 退化） | 本规格只用**匀速**工况（a≈0），避开该阈值 |
| 密度比失配 → 伪尺度效应 | 配重到 ρ_body,eff = 988 kg/m³ 并实测确认 |
| 提取方法不一致 → 伪尺度效应 | 预注册提取方法（§4.2） |
| 表面张力在小尺度放大 | 记录 `We`；已在量级上判除，仅需确认非表面张力区 |
| 把合力 Z 当孤立分量 | 全程标注"从合力 Z 提取的载荷"，不得写成"孤立吸入力"（`Paper_Notes` §5、§14） |

## 6. 什么结果会推翻本文件的前提

**B1 可能失败，且失败是有价值的。** 若 `F_suction/W` 随尺度显著变化，
则说明：

- 空腔体积亏缺假说**不足**（比值本应尺度无关），或
- 该现象含有未被建模的尺度相关机制（如表面张力在某一尺度区间不可忽略、或粘性效应）。

两种情况下，`D002-001` 都转为**无条件** `Needs CDFV experiment`，
且 `P003` §7.5 的 H4 假说被证伪——**这本身是可发表的结果**
（"自由液面载荷的量级不遵循简单 Froude 相似"）。

## 7. 与 Stage 1 迁移条件的关系

**B1 不需要 CDFV-001 的任何绝对数值。** 它检验的是无量纲比值
`R = (F_suction/W)_λ=0.5 ÷ (F_suction/W)_λ=1.0`，不涉及 CDFV-001 的绝对尺度、
质量或速度包线。

**2026-10-20 更新**：本节原题为「与 Stage 1 四个 `Blocked` 参数的关系」，
并断言 `T10` 仍然有效。**两者都已过时**：

| 项 | 原状态 | 现状态 |
|---|---|---|
| Stage 1 | 4 个 `Blocked` 单元格 | 已重构为**无量纲组 + 迁移条件**（见 `P003_Stage1_Reframing.md`） |
| `T10` | 有效，约束「研究问题是否被框架工作挤占」 | **已原地退役**，义务转 `T18` |

**B1 与 Stage 1 的真实关系**：B1 检验的是 Stage 1 那张表里
**第一条迁移条件**（`Fr_D` 是否是不变量）的**前提本身**——
即「同一 `Fr_D` 下 `F_suction/W` 是否跨尺度不变」。

- 若 B1 通过 → `Fr_D` 匹配是一条**成立**的迁移条件，Stage 1 的其余条件可以在此之上使用；
- 若 B1 不通过 → **`Fr_D` 单独不足以刻画迁移**，Stage 1 的第一条条件被推翻，
  必须做 CDFV 专用实验（`D002-001` 的 Stage 4 选项 3）。

**所以 B1 不是 Stage 1 的后续，而是 Stage 1 第一条件的独立检验。**

**`T10` 与 `T18` 都不是 B1 的前置条件。** `T18`（CDFV-001 独立规格）
只在最后一步需要：判定该比值对 CDFV-001 是 material 还是 immaterial。
