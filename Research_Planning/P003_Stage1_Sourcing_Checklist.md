## 1. 四个参数各自的取材判据

对每个参数，回答四件事：**取值来源 / 允许的替代路径 / 不确定度要求 / 可接受性判据**。

### 1.1 出水速度范围（Water-exit velocity）

| 项目 | 内容 |
|---|---|
| 物理含义 | 出水过程的垂向速度区间，决定自由液面载荷是否可能显著 |
| 首选来源 | CDFV-001 的任务需求或概念设计中的水动力段速度包线 |
| **关键**：P002 的速度范围（0.1–0.5 m/s）**只是文献范围，不是 CDFV 范围**。P003 §11 风险表已列"Treating 0.25 m/s as universal"为需控制的风险 |
| 允许的替代路径 | 若 CDFV 速度包线未定，可先做**无量纲筛选**（见下 §3.2），把问题改写为 "在什么速度区间内 P002 报告的载荷量级（≈10% 重量）会超过 CDFV 的载荷容差" |
| 不确定度要求 | 必须给出区间与依据；单一数值不可接受 |
| 可接受性判据 | 该区间能明确回答"是否与 P002 的 0.1–0.5 m/s 重叠"，或明确声明不重叠 |
| 当前状态 | **Blocked — 需要 CDFV 速度包线或一次显式建模假设** |

### 1.2 质量 / 重量基准（Mass / weight reference）

| 项目 | 内容 |
|---|---|
| 物理含义 | 自由液面载荷的**比较基准**——P002 的报告方式正是"最大吸入力 ≈ 10% 车重"，故无重量则无比较 |
| 首选来源 | CDFV-001 概念设计的目标全重（含载荷、能源、结构） |
| 允许的替代路径 | 若全重未定，可用**任务需求反推的区间**（如载荷 + 续航要求 → 能源质量 → 全重区间），并显式标注为**估算**而非设计值 |
| **禁止** | 不得使用 P002 的 2.030 kg。P003 §6 原文："If an input is unavailable, record 'Blocked — source required.' Do not substitute P002 cylinder values." |
| 不确定度要求 | 估算路径必须给出估算方法与被忽略项 |
| 可接受性判据 | 能计算"载荷 = 重量的 x%"这一比值，且 x 的量级可判定 |
| 当前状态 | **Blocked — 需要 CDFV 全重或一次显式的估算记录** |

### 1.3 主体几何：直径与长度（Main diameter / length）

| 项目 | 内容 |
|---|---|
| 物理含义 | 决定浸没体积随浸深的变化率，即浮力梯度；也决定 P002 圆柱拟合是否可能迁移 |
| 首选来源 | CDFV-001 概念设计的机身尺度 |
| 允许的替代路径 | 若尚未选型，可先用**参数化符号表示**（D, L 作为符号），只回答"自由液面载荷是否随 D/L 单调变化"这一结构性问题；P003 §7 Stage 3 明确"a symbolic term is acceptable initially" |
| **禁止** | 不得使用 P002 的 0.090 m / 0.323 m 作为 CDFV 值。可把它们**仅**用作文献对照列 |
| 不确定度要求 | 若用符号，须说明后续如何取值 |
| 可接受性判据 | 要么有设计值，要么明确是"待定的设计变量"并在模型中作符号处理 |
| 当前状态 | **Blocked — 需要 CDFV 几何或一次显式的符号化处理** |

### 1.4 过渡姿态（Transition attitude）

| 项目 | 内容 |
|---|---|
| 物理含义 | P002 的姿态条件为 5°–25°（@0.1 m/s，见 P003 Stage 1 表引用 P002 §4.3），而 Ref-01B 基线按**固定 0° 直立**处理（`CDFV-001_Reference_Configuration.md`：Initial attitude 0°）。**二者不一致，必须记录** |
| 首选来源 | CDFV-001 出水段的姿态控制策略或预期姿态史 |
| 允许的替代路径 | 若姿态未定，明确声明"本阶段仅评估 0° 直立"，并把姿态耦合列入排除项与限制（Ref-01B 已如此处理） |
| **关键风险** | P003 §11 已列"Hidden coordinate mismatch"与"Confusing resultant Z with isolated suction"。姿态从 0° 改为 5°–25° 会改变自由液面的对称性，可能使 P002 的轴对称假设失效 |
| 不确定度要求 | 须说明所选姿态与 P002 姿态范围的差异，及其对结论适用性的影响 |
| 可接受性判据 | 姿态假设被显式记录，且其与 P002 的差异被列为结论的适用边界 |
| 当前状态 | **Blocked — 需要 CDFV 姿态条件，或一次显式的"仅 0°"限定声明** |

## 3. 三条可行路径（按代价排序）

### 3.1 路径 A：取得 CDFV-001 设计输入（最彻底）
补齐概念设计的四个量。产出：Stage 1 表填满，P003 可进入 Stage 2/3。
代价：需要一次概念设计工作或外部输入；不是纯文献任务。
**风险**：若输入来自"合理猜测"，会污染后续所有结论。

### 3.2 路径 B：无量纲筛选（最便宜，且不违反溯源规则）
**不引入任何 CDFV 数值**，而是改写问题为：

> "P002 报告的载荷量级（最大吸入力 ≈ 10% 车重，且在 0.25 m/s 以上近似不变）
> 在什么条件下会对 CDFV-001 构成**不可忽略**的载荷？"

具体做法：以"载荷/重量比"与"载荷/容差比"为判据，用符号或区间运算，输出
**"material / immaterial-within-range / unresolved"** 三者之一。
产出：满足 P003 §9 的结果三态要求，且**不需要四个 CDFV 数值**。
**限制**：结论会带较强的条件性（"若 D/L 为某量级则…"），但这是**诚实**的条件性。

### 3.3 路径 C：显式承认 unresolved
若 A 与 B 都不可行，则按 P003 §9 把结果标为 `unresolved`，并在 §10 预期产出中
创建后续任务（"需要 CDFV 概念设计输入"）。产出符合验收标准，但**不推进 D002-001**。

**建议（判断）**：先做 **路径 B**。理由：它最便宜、不违反禁止替代条款、且直接产出
P003 §9 所要求的三态结论之一。若 B 的结论是"条件敏感"，再决定是否为收敛条件而走 A。
**路径 B 的产物本身也是 EEM 环闭合的合格产出**（`D-ANRI-002` 的 G1 判据只要求三态结果
+ 更新 `D002-001` + 产出 `KU003-001`）。
