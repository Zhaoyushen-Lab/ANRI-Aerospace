## 1. 为什么候选只能是"过渡动力学"域内的问题

`Research_Planning/Active_Questions.md` 的依赖图是明确的：

```
AQ001（过渡动力学） → supports → AQ002（构型优化） → supports → AQ003（跨域控制）
```

且 AQ002 条目标注：**`Current Blocker: Requires better understanding of AQ001`**。

因此：

| 候选来源 | 能否作为 P004 | 理由 |
|---|---|---|
| AQ002 构型优化 | ❌ **不可以** | 被 AQ001 阻塞，且属于**不同域**；用它等于跳级 |
| AQ003 跨域控制 | ❌ **不可以** | 依赖 AQ002，跳两级 |
| **AQ001 的子问题** | ✅ **可以** | 同域、未闭合、可复用同一闭环 |

**这不是我保守。** 用 AQ002 做 P004，测的会是"换了领域还能不能跑"，
而 G2 要求的是"同域第二个问题能否复用"。两者是不同的检验，不能混用——
用跨域问题冒充同域复用，会让 G2 变成**虚假通过**。

## 2. 三个候选子问题

以下三个都取自 AQ001 的 `Research Question` 列表
（added mass / buoyancy / hydrodynamic forces / aerodynamic forces /
water impact / flow separation），并已排除与 P003 重叠的部分。

### 候选 A：附加质量（added mass）在过渡过程中是否可忽略？

| 项 | 内容 |
|---|---|
| **可证伪问题** | 在 CDFV-001 的出水速度区间内，附加质量项对垂向合力的贡献是否低于某个阈值？ |
| **与 P003 的关系** | P003 处理自由液面载荷（浮力亏缺）。Ref-01B 基线在模型层面**显式排除了** added mass（README：`drag is omitted, and added mass is omitted`）。所以这是同一域内一个**已被排除但未被论证**的项，不是重复劳动 |
| **所需外部资源** | **无**。纯解析 + 已有几何（P002 圆柱），可用与 P003 相同的量纲筛选法 |
| **能否复用现有 schema** | ✅ **应该可以**。仍是单一 claim + evidence + validator 结构 |
| **第一个可执行动作** | 用与 P003 §7.5 相同的**量级检验方法**（四个候选机制 × 量纲尺度），算出 added mass 力的量纲尺度 |
| **风险** | 可能得出"可忽略"的结论——**这不是失败**，`P003` §9 明确允许 `immaterial-within-range` |

**为什么它是最强候选**：Ref-01B 基线**主动排除**了 added mass（写在 README 里）。
一个"我们排除了 X，X 真的可以忽略吗"的问题，是**最自然、最容易通过同行审查**的
第二个闭环。而且它不需要任何外部资源。

### 候选 B：出水冲击载荷（water impact）是否与速度单调相关？

| 项 | 内容 |
|---|---|
| **可证伪问题** | 入水/出水冲击的峰值载荷是否随速度单调增长，还是存在临界速度？ |
| **与 P003 的关系** | P003 研究的是**稳定上升段**的浮力亏缺；冲击是**瞬态**，物理机制不同 |
| **所需外部资源** | ⚠️ **需要数据**。现有 Ref-01B 是准静态模型，**不含冲击瞬态**。P002 的实测数据在 `Paper_Notes` 里有描述但**未数字化** |
| **能否复用现有 schema** | ✅ 可以 |
| **第一个可执行动作** | 先确认 P002 原文是否有可直接数字化的冲击峰値图（`Paper_Library` 里的 PDF 有） |
| **风险** | 如果必须数字化图像，会引入 P003 已排除的"曲线读取"自由度问题 |

**弱点**：它触碰"数字化"这条路，而 `P003` §7.5.7 已经论证过数字化比对
**不能回答迁移问题**。同样的陷阱可能重现。

### 候选 C：流分离（flow separation）是否由 Froude 数控制？

| 项 | 内容 |
|---|---|
| **可证伪问题** | 出水中流动分离的发生是否由单一临界 Froude 数决定？ |
| **与 P003 的关系** | **高度相关但不重叠**。P003 的 H4（空腔体积亏缺）假说**暗示**了分离，但 P003 明确说该假说"尚无反演证据"。C 是**直接检验分离本身**，而 P003 只是**推断分离的后果** |
| **所需外部资源** | ⚠️ **可能需要可视化数据**（侧视成像）。P002 有自由液面图像但未量化 |
| **能否复用现有 schema** | ✅ 可以，但可能需要新增 evidence 类型（图像证据） |
| **第一个可执行动作** | 检查 `Paper_Library` 的 P002 PDF 是否有可提取的分离角/空腔长度数据 |
| **风险** | **最高**。它可能变成"重做 P002 的实验"，而不是一个可在一周内闭环的问题 |

**最强点**：它与 P003 的结论直接咬合——P003 说"空腔亏缺假说未验证"，
C 正好验证它。**如果做成，P003 和 P004 会形成真正的知识累积链**，
而不是两个松散的例子。

## 3. 按 G2 判据的比较

`D-ANRI-002` 的 G2 要求"同域第二个问题复用同一闭环"。
关键不是"问题有趣"，而是**它能证明闭环可复用**。

| 判据 | A（附加质量） | B（冲击） | C（流分离） |
|---|---|---|---|
| 同域（过渡动力学） | ✅ | ✅ | ✅ |
| 与 P003 不重复 | ✅ 基线显式排除 | ✅ 稳定段 vs 瞬态 | ⚠️ 高度相关 |
| **不需要外部资源** | ✅ **是** | ❌ 需数据 | ❌ 可能需图像 |
| 可复用现有 schema | ✅ | ✅ | ⚠️ 可能需扩展 |
| 能在 1–2 周内闭环 | ✅ 很可能 | ⚠️ 不确定 | ❌ 不太可能 |
| 能形成知识累积链 | ⚠️ 独立 | ⚠️ 独立 | ✅ **强** |
| 结论即使"可忽略"也有价值 | ✅ | ⚠️ | ❌ |

**纯按 G2 的执行风险排序：A < B < C。**

**纯按科学价值排序：C > A ≈ B。**

这两个排序**不一致**，这正是需要你决定的点。

---

## 4. 我的建议（判断，不是结论）

**建议先做 A。** 理由不是 A 更有趣，而是：

1. **G2 检验的是"闭环能否复用"，不是"能否做出好科学"。**
   A 在这件事上风险最低——如果 A 都跑不通，说明框架有问题，
   而这个问题**必须尽早暴露**，不能等到做了一个漂亮的问题才发现。
2. **A 不需要外部资源**。B 和 C 都可能卡在数据上，而卡住会让 G2 无限期推迟。
3. **A 的"可忽略"结论是合法产出**。`P003` §9 已确立三态判据，
   `immaterial-within-range` 也是合格结果。

**但如果你更看重科学价值而非 G2 的快速达成，选 C。**
C 若做成，P003 的 H4 假说会被真正检验，两个问题会连成一条链——
那是"研究"而不是"流程演示"。

**B 我不推荐**：它同时承担了"需要数据"和"触碰数字化陷阱"两个风险，
而回报不如 C。

   **相同的四问格式**（取值来源 / 允许的替代路径 / 不确定度要求 / 可接受性判据）；
2. 跑一次**量纲筛选**（复用 `P003` §7.5 的方法），得出三态结论之一；

**这一步做完，`loops_closed` 仍然是 1**——因为闭环要求全部五环完成。
但它会证明**第二个问题能启动**，而这是 G2 的前置。
