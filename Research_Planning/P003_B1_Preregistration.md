## 1. 假设（可证伪形式）

| ID | 假设 | 证伪条件 |
|---|---|---|
| **H-B1** | 在几何、密度比、Froude 数、浸没史匹配的条件下，`F_suction/W` 与尺度无关 | 两尺度比值超出 1 ± 0.20 |
| H-B1a | 若 H-B1 被证伪，方向与表面张力主导一致（小尺度偏大） | 比值随 λ 增大而增大 |
| H-B1b | 若 H-B1 被证伪，方向与粘性主导一致（小尺度偏小） | 比值随 λ 增大而减小 |

**H-B1 是主假设**；H-B1a / H-B1b 是辅助假设，只在 H-B1 被证伪时用于机制辨识。

## 2. 冻结的判据

| 项 | 值 | 说明 |
|---|---|---|
| 主判据工况 | **Fr_D = 0.266**（饱和点） | 唯一必需的比较工况 |
| 判据量 | `R = (F_suction/W)_λ=0.5 ÷ (F_suction/W)_λ=1.0` | 无量纲比值的跨尺度比 |
| 通过区间 | **1 ± 0.20** | 见 §4 的来源与局限 |
| 通过 | H-B1 未被证伪 | `D002-001` → **Accepted**（附无量纲适用条件） |
| 不通过 | H-B1 被证伪 | `D002-001` → **Needs CDFV experiment**（无条件） |
| 数据不可用 | 见 §7 排除规则 | 记为 `unresolved`，不记为通过或不通过 |

**判据锁定声明**：`R` 的计算式、`F_suction` 的提取方法（§3）、以及 1 ± 0.20 的区间，
在本文件签署后**不得修改**。若必须修改，须新建 `v2` 预注册并说明修改理由与时间，
且 `v1` 下已获得的任何数据必须重新标注为"探索性"，不得用于主判据。

## 3. 冻结的提取方法

P002 报告的"吸入力"是**从合力 Z 中提取并拟合的残差**，不是孤立分量
（`Paper_Notes/P002_Free_Surface_Hydrodynamics_HAUV_2022.md` §5、§14）。因此提取方法的选择直接决定结果。

### 3.1 冻结项

| 项 | 冻结值 | 备注 |
|---|---|---|
| 测量的原始量 | `F_z(t)` 与 `z(t)` | 不做任何在线滤波以外的处理 |
| 采样率 | ≥ 1000 Hz | 与 P002 一致（`Paper_Notes` §6.2） |
| 在线滤波 | 仅记录滤波器类型与截止频率；**两尺度必须使用同一个滤波器设置** | P002 的滤波器未报告，故本规格自定并要求一致 |
| 提取窗口 | 自 `z(t)` 穿越 `z = 0` 起，至 `z = +L/2` 或力信号回到稳态（以先到者为准） | 覆盖整个过自由液面过程 |
| 残差定义 | `F_suction(t) = F_z(t) − [W − ρ_w g V_sub(t)]`，其中 `V_sub(t)` 由几何与 `z(t)` 算出 | **与 Ref-01B 的基线形式一致**，故可复用 |
| 报告量 | `F_suction = max_t |F_suction(t)|`（取峰值） | 与 P002 的"最大吸入力"口径一致 |
| 拟合 | **不做拟合**。直接用上式的峰值 | 消除拟合形式这一自由度 |

> **关键选择说明**：本规格选择**不做拟合**（P002 做了拟合）。
> 理由：拟合形式是最大的自由度来源；直接使用与 Ref-01B 基线同形的残差定义，
> 既减少自由度，又使结果可与本仓库已有的 `constraint_force_N` 直接对照。
> **代价**：本结果与 P002 的拟合值**不可直接数值比较**，只能比较量级与趋势。
> 该代价已被接受并记录。

### 3.2 必须同形的量

以下量在两尺度上必须使用**同一个**定义/算法，否则测到的差异可能来自算法：

- `V_sub(t)` 的计算（同一几何函数，按 λ 缩放）
- 穿越时刻 `z = 0` 的判定（同一插值方法）
- 峰值搜索窗口
- 异常点剔除规则（§7）

## 4. 通过阈值 1 ± 0.20 的来源与局限

- **来源**：P002 自报重复性误差 ≤15%（`Paper_Notes` §6.2）。两尺度各含该量级误差，
  按误差传播，最小可辨差异约为 20%。
- **局限（必须随结果报告）**：
  1. 20% 是**误差传播下的最小可辨差异**，不是物理显著性阈值。
     真实的尺度效应若小于 20%，本实验**无法与噪声区分**。
  2. P002 的 ≤15% 是其自身装置的重复性；本实验装置的重复性须实测。
     **若本装置重复性 >15%，则必须在测量前按实测值重算并修订阈值**，
     修订须记录在 §8。
  3. 该阈值是**判断，不是测量**。

## 5. 样本量与重复

| 项 | 值 | 理由 |
|---|---|---|
| 每工况重复次数 | **≥ 3** | 与 P002 一致；用于估计本装置重复性 |
| 尺度数 | **2**（λ=0.5, λ=1.0） | 最少可行子集 |
| 工况数 | **1**（Fr_D = 0.266） | 主判据工况 |
| 总测量数 | **≥ 6** | 2 尺度 × 3 重复 |

**报告方式**：报告每次重复的 `F_suction/W`（不只报均值），并报告标准差。
`R` 由两尺度的均值计算，同时报告由标准差传播得到的 `R` 的不确定度区间。

## 6. 混杂因素的冻结控制

| 混杂因素 | 冻结控制 |
|---|---|
| 连接杆 | 两尺度使用**几何相似**的杆（杆径/柱径、杆长/柱长恒定）。**不得沿用 P002 的 1.0 / 0.1 / 0.30 m**（非相似） |
| 配重 | 两尺度均实测并配到 `ρ_body,eff` 相等，目标 **988 kg/m³**；实测值须报出 |
| 加速度 | **仅匀速工况（a ≈ 0）**，避开 P002 的 ≥0.2 m/s² 退化区 |
| 水温/密度 | 记录水温并据此取 `ρ_w`；两尺度测量期间水温差 < 2 °C |
| 表面张力 | 记录 `We = ρv²D/σ`；确认落在非表面张力区 |
| 初始浸没 | `z₀/L` 两尺度相等，实测并报出 |

## 7. 排除规则（测量前冻结）

一次重复满足以下任一条即**排除**，且排除原因须逐条记录：

1. 在线滤波前的 `F_z(t)` 出现饱和/削顶（超量程）。
2. `z(t)` 的穿越点无法判定（信噪比不足）。
3. 目视观察到非轴对称空腔（侧视/前视任一方向明显不对称）——**记录但排除**，
   因为本假设要求轴对称。
4. 装置重复性实测值 >15% 且该次重复超出 ±3σ。

**排除上限**：任一工况排除 >2 次时，该工况记为 `unresolved`，不得为凑数而放宽规则。
**禁止**：不得在看过 `F_suction` 结果后再新增排除规则。
