# CDFV-001-Ref-01S 实验需求说明（实验室沟通版）

## 1. 一句话请求

申请在哈尔滨工程大学船海相关实验条件下，开展一个固定姿态、单轴垂直出水的缩比模型实验，用于测量过自由液面过程中的垂向载荷，并将原始数据接入 ANRI Research Object。

## 2. 研究问题

在给定几何、质量、重心和运动条件下，垂直出水过程中的实测垂向力是否需要在重力/浮力基线之外增加自由表面载荷项？

本实验用于检验模型边界和载荷趋势，不直接宣称验证完整 CDFV 飞行器性能。

## 3. 初始模型（Ref-01S 候选）

| 参数 | 候选值 | 状态 |
|---|---:|---|
| 几何缩比 | 0.5 | 待实验室确认 |
| 主体直径 | 0.045 m | 候选 |
| 主体长度 | 0.1615 m | 候选 |
| 质量 | 0.254 kg | 候选，需配重校准 |
| 重心 z 坐标 | -0.0875 m | 待坐标确认 |
| 出水速度 | 0.071–0.354 m/s | 候选，按 Froude 相似缩放 |
| 姿态 | 0°，固定 | 初始方案 |
| 运动 | 垂直向上，单自由度 | 初始方案 |
| 流体 | 清水，温度实测 | 待实验定义 |

## 4. 需要的设备与能力

- 综合试验水池、拖曳水池或适合的透明水槽；
- 可提供稳定垂直运动的拖车、直线执行器或等效装置；
- 三向力/六分力传感器，量程和精度由实验室根据预估载荷确认；
- 位移或速度记录；
- 必要时使用水下/侧视摄像机记录自由液面变化；
- 传感器标定、时间同步和原始数据导出能力。

## 5. 测量与实验矩阵

首轮只做最小矩阵：

- 速度：0.071、0.177、0.354 m/s（或设备允许的等效三档）；
- 姿态：0°；
- 每个工况至少 3 次重复；
- 记录：时间、位移、速度、加速度、垂向力、可用时记录三向力/力矩；
- 水温、模型质量、配重、初始浸没深度和传感器标定结果随每次试验保存。

如果实验室认为加速度或振动会污染结果，第一阶段只保留恒速出水。

## 6. 数据交付

每个工况交付：

- 原始数据文件；
- 标定文件和单位说明；
- 设备、采样率、滤波和时间同步说明；
- 重复实验记录；
- 异常点和剔除理由；
- 实验报告或技术人员确认记录。

数据将映射到：

```text
RO-CDFV-001-Ref-01S
  └── Experiment Object
      ├── raw measurements
      ├── calibration
      ├── conditions
      └── uncertainty
```

## 7. 实验室需要确认的问题

1. 哪个水池或水槽最适合该速度和行程？
2. 是否可以使用现有六分力传感器或需要外接传感器？
3. 垂直运动装置的速度、加速度、行程和同步接口是什么？
4. 模型最大尺寸、质量、配重和夹具是否满足安全要求？
5. 是否需要课题组负责人、设备管理员和安全培训审批？
6. 设备预约、培训、耗材和测试费用如何计算？
7. 原始数据、署名和后续论文中的实验室贡献如何记录？
