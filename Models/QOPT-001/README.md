## 3. ★ 哪一项才是真检验

> **T1–T4 都可能因为"代码什么都不做"而通过。**
> **唯一真正检验传播的是 T5。**

**理由**：

- T1（z=0）——一个恒等函数就通过
- T2（能量守恒）——只要用的是酉变换（FFT）就通过
- T3（全零相位屏）——`exp(i·0) = 1`，乘法都省了也通过
- T4（平面波）——平面波在自由空间本就不变，不传播也通过

**而 T5 要求**：模拟场必须与高斯光束的闭式解
`w(z) = w0·sqrt(1 + (z/z_R)²)`、`z_R = π·w0²/λ`
**同时对上束宽与峰值。**

**本组参数下**：

```
λ = 500 nm,  w0 = 0.5 mm  →  z_R = 1.5708 m
z = 5.0 m                 →  w(z) = 1.6682 mm
```

**模拟给出 1.6682 mm。这是传播代码正确的最强证据。**
