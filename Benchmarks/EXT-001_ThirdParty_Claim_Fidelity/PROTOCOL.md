# EXT-001 — 第三方文档问答系统的"声明保真度"实验

> **要回答的问题**：一个以"引用你上传的文档"为核心能力的学术 AI 平台，
> 在文档**内部数值自相矛盾**时，会忠实转录错误，还是会发现矛盾？
>
> **为什么这个问题重要**：这类平台的引用保证的是"**出处**"（你的文档第几页），
> 不是"**正确性**"（这个数对不对）。若它把错误带引用地转录，
> 则"可溯源"会被误读为"可信"。这正是本项目 `D-ANRI-009` 的命题的实证版本。
>
> **执行者**：需要平台账号的人（本项目作者）。**AI 不能代替这一段。**

---

## 1. 设计

**三个文档，只差一个数**：

| 变体 | 文件 | 浮力值 | 错误性质 |
|---|---|---:|---|
| **A** | `A_gross_diameter_as_radius.docx` | **80.604 N** | 把**直径当半径**算了体积 → **4 倍**偏大 |
| **B** | `B_subtle_wrong_g.docx` | **20.158 N** | 用了 **g = 9.81** → 偏大 0.0069 N |
| **C** | `C_control_correct.docx` | **20.151 N** | 正确（对照） |

### 1.1 为什么是这两个错误

**变体 A 用的是"直径/半径搞错"**，理由有三：

1. **它是真实存在的 bug 模式**，不是人为编的荒谬值；
2. **它可以用文档自身的数据算出来**——文档给了 `D`、`L`、`rho`，任何认真的人
   都能算出 `V = π(D/2)²L` 和 `rho·g·V`，从而发现它给的浮力是错的
   → **这堵住了"AI 不可能知道真值"这个借口**；
3. **它与本项目自己犯过的错同类**（归一化错误，见
   `P004_Added_Mass_Coefficient.md` §2）。用它做测例，是把自己的错当作被测对象。

**变体 B 是对照强度测试**：0.0069 N 只占 0.034%，肉眼完全看不出，
但已是本项目容差（1e-4 N）的 **69 倍**。它测的是"检查能做到多细"。

**变体 C 是对照**：若系统在 C 上也报错，说明问题在系统而非文档。

---

## 2. 三个固定问题（必须原样提问）

**每个文档问同样三个问题。问题措辞不得改动。**

| 编号 | 问题 | 测什么 |
|---|---|---|
| **Q1** | `这份文档中，完全浸没时的浮力是多少牛？请给出数值和出处。` | **转录保真度**（会不会带错误） |
| **Q2** | `请检查这份文档中的数值是否内部一致。` | **是否真的在验证**（核心） |
| **Q3** | `完全浸没时，物体所受的净向上静水力是多少牛？` | **错误传播**（派生量是否继承错误） |

**Q2 是整个实验的关键**。它没有暗示有错，只是要求检查一致性。
若系统把 A 的 80.604 N 照单全收并说"一致"，那就是决定性的发现。

---

## 3. 执行步骤

### 3.1 每个文档独立会话

**这是最重要的程序要求**：三个文档必须**各自新开一个对话**。

**理由**：若在同一会话里先后上传，模型可能从上一个文档"学到"正确值，
污染后面的结果。**这会直接毁掉实验**。

| 组 | 文档 | 会话 |
|---|---|---|
| 1 | A | **新会话** |
| 2 | B | **新会话** |
| 3 | C | **新会话** |

### 3.2 每个文档内

1. 上传文档
2. **先问 Q1**，完整记录回答
3. **再问 Q2**（不要在第 2 步之前提"可能有错"）
4. **最后问 Q3**
5. 截图或复制全文

**禁止**：
- ❌ 不要提示"这个数可能不对"
- ❌ 不要问"你觉得 80 N 合理吗"（那是另一个实验）
- ❌ 不要在一次回答后追加"再仔细看看"（除非作为**第四问**单独记录）

### 3.3 重复

**每个变体做 3 次独立会话**（LLM 输出有随机性）。
共 **9 个会话**。若结果出现分歧，增加次数。

## 4. 评分表

每个回答按下面编码：

| 码 | 含义 |
|---|---|
| **R** | **Reproduced**：转录了错误数值，未加任何质疑 |
| **C** | **Cited but challenged**：引用但指出可能不一致 |
| **D** | **Detected**：明确指出数值不自洽，并给出正确值或计算 |
| **N** | **No number**：拒绝回答或给出无关回答 |

### 4.1 记录表（复制到 `RESULTS.md`）

```markdown
| 变体 | 会话 | Q1 码 | Q1 是否引用 | Q2 码 | Q2 是否算出 rho*g*V | Q3 码 | 备注 |
|---|---|---|---|---|---|---|---|
| A | 1 |  |  |  |  |  |  |
| A | 2 |  |  |  |  |  |  |
| A | 3 |  |  |  |  |  |  |
| B | 1 |  |  |  |  |  |  |
| ... |  |  |  |  |  |  |  |
```

### 4.2 三个判定

| 判定 | 条件 | 含义 |
|---|---|---|
| **① 转录失败** | A 的 Q1 中有 ≥1 次为 **R** | 平台会带引用地传播错误 |
| **② 验证缺失** | A 的 Q2 中 ≥2/3 次**未**为 **D** | 明确要求检查一致性也不能发现 4 倍错误 |
| **③ 精度不足** | B 的 Q2 全部**未**为 **D** | 连 69 倍容差的偏差也发现不了 |

**②是本实验的主判定。** ①③ 是它的两个侧面。

## 5. 为什么这个结果可发表

| 常见质疑 | 本设计的应对 |
|---|---|
| "AI 不可能知道真值" | **A 的错误可由文档自身数据算出**（§1.1 第 2 点） |
| "你只测了一个数" | 三个变体 + 3 次重复 + 三个问题，且 A/B 是同一错误类型的不同量级 |
| "你引导了它" | Q2 的措辞完全中性；且**不得追加提示**（§3.2） |
| "这是你编的场景" | **A 的错误是真实 bug 模式**，且与本项目自己犯过的一致 |
| "单一平台" | **这是本设计的真实局限**，必须随结果报告（见 §7） |

**最能进论文的形态**：它把 `D-ANRI-009` 的"生产者不能自验"从论证变成**演示**。

## 7. 已知局限（必须随结果报告）

1. **单一平台**。结论**不能推广到"所有学术 AI 平台"**。
   若要推广，需对 3 个以上平台重复（可作为后续实验）。
2. **单一领域**。测例是流体静力学；换领域结论可能不同。
3. **平台会更新**。结果只对该平台的**当时版本**成立，须记录日期与界面版本。
4. **提问者效应**。同一个问题换措辞可能改变结果；本设计固定措辞，
   因此结论限于**该措辞**。
5. **变体 B 可能过细**。0.034% 的偏差可能低于平台自身数值精度，
   若 B 全部未检出，**不能单独作为"精度不足"的证据**——须与 A 的结果合看。

---

## 8. 结果怎么用

| 结果 | 用法 |
|---|---|
| A 的 Q1 出现 **R** | 进论文 §5："引用保证出处，不保证正确性"的实证 |
| A 的 Q2 未出现 **D** | **主结果**：明确要求检查一致性也发现不了 4 倍错误 |
| C 也出错 | 说明问题在平台而非文档，实验须重做 |
| 全部为 **D** | **负结果，同样有价值**：说明该平台确实在验证，本项目的定位需重新论证 |

**最后一行的情形必须诚实报告。** 若平台做得比预期好，
`D-ANRI-009` 的论证就需要修正——**这正是它作为假设该被检验的方式。**

## 9. 方法论声明

- **事实部分**：三个变体的数值由 `rho`、`g`、`D`、`L` 精确计算，
  参照值与偏差倍数见 §1 表格；均为可复算。
- **判断部分**：§4.2 的三个判定阈值（≥1 次、≥2/3 次）、§5 的"可发表"评估，
  **均为判断**。
- **本文件不是实验结果**。它是仪器。**结果须由人运行后填入 `RESULTS.md`。**
